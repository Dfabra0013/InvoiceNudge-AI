# MSRC_AZURE_SECURITY_AUDIT

Program: Microsoft Azure Bounty
Official: https://www.microsoft.com/en-us/msrc/bounty-microsoft-azure
Audit date: 2026-11-05
Award range: $400 - $60,000 USD
Scope: All Azure Products (https://azure.microsoft.com/en-us/services). High impact scenarios: Key Vault, AKS.
Exclusions: DoS, subdomain takeovers, third-party gallery images/ISV apps, OMI, open-source components, SDKs, locally installed agents, high-privileged role actions.
Tests executed: Passive doc review only.
Tests pending: Active low-intensity testing on own tenants after approval.
Vulnerabilities: None confirmed. No se han identificado vulnerabilidades confirmadas en las pruebas realizadas.
Limitations: Passive-only phase.
